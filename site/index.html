Inside the FT-710's firmware

An independent study of the Yaesu FT-710 HF/50/70 MHz transceiver, done on the owner's own radio. All four firmware images are decoded and decompiled, every CAT command is mapped, and the whole radio is explained in an illustrated guide.

Highlights

What the project has found so far. Each card links to the chapter of the guide that explains it.

Four computers, not one

A Renesas RX651 (MAIN) runs the radio and CAT, a Renesas RZ/A1H (DISPLAY) runs the touch screen and SD card, an NXP i.MX RT685 does the audio DSP, and a Xilinx Artix-7 FPGA does the SDR.

Chapter 1 →

Firmware updates decoded

Each .SFL update file is scrambled with a fixed 43-byte key and protected by a salted CRC-32. All four now decode cleanly, and the DISPLAY CPU is shown to program every other chip.

Chapter 4 →

114 CAT commands, 22 undocumented

MAIN firmware V01-12 accepts 114 commands; the manual lists 92. The rest range from harmless reads to factory reset, region change and raw EEPROM access.

Risks and backups →

How the chips talk

Three slow control links and three fast SPI data links. MAIN writes numbered registers in the FPGA and the DSP with short ASCII commands; scope and audio data skip MAIN entirely.

Chapter 2 →

FPGA bitstream to Verilog

The SDR bitstream was turned into a cell netlist, structural Verilog and a Verilator model of the whole FPGA, with a hand-written model of its UART link.

Chapter 7 →

Custom firmware looks possible

No image is signed or encrypted, and every chip has a debug or boot header. Two small patches and an FPGA test are planned; none has been applied to a radio.

Chapter 8 →

Undocumented CAT commands

The firmware answers commands Yaesu doesn't publish. They are documented here with what each one changes, how risky it is, and how to get back.

Back up before you experiment Some commands reset every setting, change the radio's region, or overwrite the factory calibration. A lost calibration comes back only from your own backup or a service alignment.

Risks, paths back and backups: every undocumented command with its risk and how to undo it, what data lives where, and step-by-step backup and restore (SD card, a read-only backup script, and a full EEPROM dump).

The firmware reference: the exact formats of SP, E8/E9, ZZ, JP, FD, PE, EO and the rest, with the addresses they were decoded from.

All 104 main-table commands: what the firmware really does for each documented command, and where it differs from the manual.

Checked on a real radio On 2026-10-28 the read-only commands were sent to the owner's FT-710. Every reply matched the decoded format, and the radio reported the firmware versions this project analyses (MAIN V01-12, DISPLAY V01-08, SDR V01-04, DSP V01-01). Results.
